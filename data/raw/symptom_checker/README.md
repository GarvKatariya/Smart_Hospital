# Symptom Checker Dataset

This dataset contains a mapping of diseases to their common symptoms. 
It is used to train the GRU-based symptom checker model for the Smart Hospital Management System.

- `symptom_disease.csv`: Contains 40 diseases with up to 17 symptoms each.
- `symptom_list.json`: A list of all unique symptoms found in the dataset.
- `disease_department_map.json`: A mapping of diseases to hospital departments.
